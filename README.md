# Kanban Workshop Playground 🛹

A throwaway repo for learning the **GitHub Projects** daily loop.
Nothing here is real — break things freely.

## Your task
1. Find the issue assigned to your number on the **board**.
2. Assign yourself → move the card to **In Progress**.
3. Create a branch and add **one file**: `interns/<your-github-handle>.md`
   (copy `interns/TEMPLATE.md` and fill it in).
4. Open a Pull Request. In the description write: `Closes #<your issue number>`
5. Request a reviewer → after it merges, watch your card land in **Done**.

> Everyone edits a *different* file, so no one's change collides with anyone else's.
